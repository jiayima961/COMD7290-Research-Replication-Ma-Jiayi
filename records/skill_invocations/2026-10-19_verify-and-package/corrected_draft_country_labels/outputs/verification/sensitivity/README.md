# Separate country influence sensitivity

This AI-proposed sensitivity was planned before fitting and requires student review. All six countries were deleted in turn; no deletion was selected because of its result. The baseline remains the faithful M1 model. Each deletion changes the sample and target context mixture, so this is an influence diagnostic, not another estimate of an identical population quantity.

Country contextual estimates can be sensitive to a single national setting because each political-system by division cell contains only one country. Article-level observations do not supply additional independent national institutional realizations. The p-value counts are descriptive stability summaries, not multiplicity-adjusted tests or a selection rule. Media contrasts remain associations; country deletion does not identify editorial gatekeeping as a cause. Full uncertainty and all deletion-specific results are in the adjacent CSV files.

Scope limit: this diagnostic evaluates M1 only and does not establish robustness of M2/M3, measurement validity, temporal generalizability or causal mechanisms.
