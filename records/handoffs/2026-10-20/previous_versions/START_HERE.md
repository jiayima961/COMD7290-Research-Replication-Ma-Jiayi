# Start here

Read this project in the following order. Current scientific results are in the main folders; earlier tests and student versions are retained as evidence.

1. **Purpose and progress:** [README](README.md), [STATUS](STATUS.md), [course checklist](docs/assignment_checklist.md).
2. **Student theory and feedback:** [student v1](records/student_inputs/2026-10-18_initial_theory_explanation_v1.txt) → [feedback 1](docs/theory_feedback_v1.md) → [student v2](records/student_inputs/2026-10-18_revised_theory_explanation_v2.txt) → [feedback 2](docs/theory_feedback_v2.md). Check the [records index](records/README.md) for receipts and attribution.
3. **Theory to test:** [theory](docs/theory.md), [matrix guide and results](docs/hypothesis_matrix.md), [complete matrix](docs/hypothesis_matrix.csv), [variable dictionary guide](docs/variable_dictionary.md), [numbered model diagrams](docs/model_diagram.md), [design](docs/design_and_models.md), [execution specification](docs/execution_specification.md). Matrix, dictionary and diagram documentation was completed on 20 October. The diagrams are AI-assisted reconstructions pending student review.
4. **Use the skills:** [all three packages, invocation examples and test evidence](docs/skills/README.md). Open the repository root, rather than its parent folder, for native skill discovery.
5. **Inspect results:** [ordered Word comparison and Python/Stata methods reports](report/verification/README.md) → [complete comparison ledger](outputs/verification/comparison_all.csv) → [12 hypothesis tests](outputs/reproduced/hypothesis_tests.csv) → [independent checks](outputs/verification/independent_checks/checks.json) → [separate sensitivity](outputs/verification/sensitivity/README.md). Earlier skill 2 results remain at their original paths.
6. **Rerun:** [teacher quickstart](docs/guides/teacher_quickstart.md) → [inputs](sources/README.md) → [analysis entry points](analysis/README.md) → [verification programs](tests/README.md).
7. **Understand the work trail:** [records index](records/README.md), [decisions](records/decisions.md), [execution logs](records/run_logs/), [reorganization map/checks](records/reorganization/2026-10-19/README.md).
8. **Individual requirements:** [three completed decision reviews and optional remaining items](records/skill3_decision_audit.md), [limitations](docs/limitations.md), [follow-up](docs/follow_up.md), [individual report draft](report/final_report_draft.md), [remaining steps](report/skill3_submission_readiness.md). Three decision reviews were completed on 20 October. Human reading, diagram ownership, personal scientific acceptance, access and final release remain separate.

New reviews and runs should use the next version or a new dated record. Do not overwrite earlier student inputs or historical execution receipts.
